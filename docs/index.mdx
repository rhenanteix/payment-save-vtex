<Note>
  O PaySave funciona dentro do Checkout v6 e só é exibido após uma recusa de pagamento.
</Note>

## O que o PaySave faz

Quando o gateway recusa uma tentativa, o PaySave apresenta as alternativas já disponíveis na loja. O cliente escolhe uma delas e o app ativa a opção nativa correspondente no Checkout.

## Garantias do fluxo

- Não captura número de cartão, CVV ou tokens.
- Não cria nem processa novos meios de pagamento.
- Não repete automaticamente uma autorização.
- Exibe o modal uma vez para cada tentativa recusada.
- Envia métricas para `window.dataLayer`.

## Métodos exibidos

O app lê `orderForm.paymentData.paymentSystems`. Na Trocafone, a validação atual contempla Pix, Pagaleve Pix Mensal Transparente, NuPay e cartão de crédito. Os ícones são os mesmos arquivos servidos pelo Checkout VTEX.
